# SnakeWeb

This is a simple classic snake game implemented for use on a web interface.

## Play the Game

You can play the game [here](https://isuruk2003.github.io/SnakeWeb/).

## Controls

- **Arrow Keys**: Move the snake
- **Space Bar**: Play/Pause the game
- **R Key**: Reset the game
- **S Key**: Toggle settings

## How to Run Locally

1. Clone the repository:
    ```sh
    git clone https://github.com/isuruk2003/SnakeWeb.git
    ```
2. Navigate to the project directory:
    ```sh
    cd SnakeWeb
    ```
3. Open `index.html` in your web browser.
